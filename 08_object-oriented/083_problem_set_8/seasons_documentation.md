# Introduction
- Python comes with a datetime module, containing the class date
- docs.python.org/3/library/datetime.html#date-objects

# Procedure
- Prompt for YYY-MM-DD (Birthday)
- Return how many minutes passed until today
- Return it in written form, not as numbers!

# Additional Information
- for simplicity, assume, the user was born at midnight (00:00:00)
- assume that the current date also is midnight.
- the term "datetime.date.today" gets today's day
- Exit via "sys.exit" if the user does not input a date
